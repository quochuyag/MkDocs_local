# Hướng dẫn tiếp tục cho khoá học Oracle RAC

## Mục tiêu
- Hoàn thiện các module còn thiếu trong thư mục modules theo phong cách dễ học, ngắn gọn, có cấu trúc và ví dụ.
- Ưu tiên nội dung tiếng Việt, có sơ đồ/flow nếu phù hợp.
- Giữ nguyên cấu trúc hiện tại của repo: mỗi module có file module_xx_guide.md.

## Phong cách viết
- Viết ngắn gọn, rõ ràng, dễ hiểu cho người mới.
- Mỗi module nên có:
  - mục tiêu,
  - nội dung chính,
  - ví dụ thực tế,
  - lưu ý và best practice,
  - tóm tắt để nhớ lâu.
- Nếu có kiến trúc hoặc luồng xử lý, nên thêm Mermaid hoặc bảng biểu đơn giản.

## Tài liệu hiện có
- Module 01, 02, 07 đã được hoàn thiện theo phong cách này.
- Cần tiếp tục hoàn thiện Module 03 đến Module 06.

## Gợi ý tiếp tục
- Module 03: cài đặt RAC, chuẩn bị môi trường, practice.
- Module 04: quản trị cơ bản, startup/shutdown, SRVCTL, CRSCTL, backup/recovery.
- Module 05: resource management, GCS/GES, monitoring và tuning.
- Module 06: services, load balancing, TAF, Application Continuity.

## Lưu ý
- Không cần chỉnh sửa PDF.
- Chỉ cập nhật các file Markdown trong thư mục modules.
- Khi viết nội dung, nên liên kết với thư mục Section tương ứng để người học dễ tra cứu.
