# 📚 Oracle Database Administration - Từ Zero đến Hero

## Bài giảng tiếng Việt

> Khóa học Oracle DBA toàn diện dành cho người mới bắt đầu.  
> Tác giả gốc: Ahmed Baraka  
> Phiên bản Việt hóa và biên soạn lại với giải thích chi tiết.

---

## 🎯 Đối tượng

- Người mới bắt đầu muốn trở thành Oracle DBA
- Sinh viên CNTT muốn tìm hiểu về quản trị cơ sở dữ liệu
- Developer muốn hiểu sâu hơn về Oracle Database
- Sysadmin muốn mở rộng kỹ năng sang lĩnh vực DBA

## 📖 Cách sử dụng

- Mỗi bài giảng có **phần lý thuyết** và **phần thực hành** riêng biệt
- Bài thực hành có hướng dẫn từng bước kèm hình ảnh minh họa
- Nên học theo thứ tự từ Section 1 trở đi
- Thực hành ngay sau khi học lý thuyết

## 🛠 Yêu cầu môi trường thực hành

- **Máy tính**: Windows 10/11 64-bit, RAM ≥ 16GB, HDD trống ≥ 150GB
- **Phần mềm**: Oracle VirtualBox, PuTTY, JRE 1.8
- **Máy ảo**: Oracle Linux 7 (srv1) + Windows Server 2016 (winsrv)
